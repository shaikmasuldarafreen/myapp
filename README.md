# PHP Learning Project

Simple PHP authentication demo with login, signup, forgot-password and reset flows.

Files:
- `public/` - front-end pages (login, signup, forgot/reset password, dashboard)
- `src/` - backend classes (`Auth.php`, `Database.php`, `config.php`)
- `database.sql` - database schema for `users` and `password_resets`

See `SETUP_AUTH.md` for full setup instructions.
